📚 Biblioteca API

API REST simples para gerenciamento interno de uma biblioteca, desenvolvida em ASP.NET Core com C# e SQL Server.

O projeto:
Cadastro de livros com controle de quantidade em estoque
Registra o histórico dos empréstimos
Atualiza o estoque do Livro ao realizar emprésto
Transações para garantir a integridade dos dados
Relatórios básicos, como livros com baixo estoque, livros indisponíveis e empréstimos por período
A aplicação está organizada em camadas (Domain, Application, Infrastructure e API), usando Entity Framework Core e o Repository Pattern
